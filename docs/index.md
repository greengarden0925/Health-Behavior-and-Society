# 健康社會行為學講義

給大學部公共衛生系學生的複習講義，目標是通過公共衛生師國考「健康社會行為學」。內容依 41 支教學影片（V00–V40）的教案整理，每章對應一支影片，章末附該主題的歷屆國考題（110–115 年，共 240 題，答案可點開查看）。

## 怎麼使用

- 上方分頁或左側選單依章節瀏覽；右側是本頁目錄。
- 每章結構：學習目標、重點內容、公共衛生應用、國考練習、參考來源、歷屆國考題。
- 「歷屆國考題對照」依章節列出所有題號，方便按主題刷題。
- 第一次出現的專有名詞與縮寫全寫，集中在「名詞全寫」。
- 使用前請先看[使用說明](usage.md)。
