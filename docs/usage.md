# 使用說明

> 各章末「歷屆國考題（110–115 年，官方題庫）」收錄考選部 110–115 年公共衛生師「健康社會行為學」選擇題及公告答案（含 114、115 年），依題意歸入對應章節。章內「國考練習」為教案記錄的題目，兩者若有重複，以官方題庫為準。

- 本講義依影片教案整理，對應影片 V00 至 V40。
- 「練習題」中的真題，取自教案所記錄的歷屆考題（111、112、114 年）與公衛師考試資訊。各章末另附「歷屆國考題（110–115 年，官方題庫）」，題目與答案來自考選部公告；章內教案記錄的題目若與之不同，以官方題庫為準。
- 「教學例」為教學用的自擬情境，非考題，也不是政策原文。
- 正式作答請以考選部官方試卷為準。
