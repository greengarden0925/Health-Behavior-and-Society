# V38 社區組織與社區工作三模式

## 學習目標

1. 說明社區組織、社區能力建構、社區賦權的概念與差別。
2. 區分社區發展與社區營造（主體不同）。
3. 說出社區工作五步驟與 Rothman 三模式的特徵。
4. 依問題性質選擇模式，並說明模式如何轉換。

## 一、基本概念

- **社區組織**：居民與社區團體為了解決共同問題，而進行的組織與合作。
- **社區能力建構**：1990 年代起普及；目標包括提供品質良好的公共服務、促進社區凝聚，以及真正的民主。
- **社區賦權**：讓社區居民取得權力與資源，決定自己的事務。
- 三者容易混淆：能力建構著重能力與資源，賦權著重權力，組織著重結構與過程。

## 二、社區發展與社區營造

| | 社區發展 | 社區營造 |
|---|---|---|
| 起源 | 1968 年臺灣省政府《社區發展工作綱要》 | 由文化部推動，以社區為主體 |
| 主體 | 政府與政策主導 | 居民自主 |

- 講義的社區營造定義取自文化部社區營造網站。

## 三、社區工作五步驟

1. 界定問題。
2. 分析資源。
3. 規劃方案。
4. 執行方案。
5. 成效評估。

## 四、社區工作的分類

- Batten（1967）。
- Taylor 與 Roberts（1985），提出五模式。
- Rothman（講義標 1995，**首次提出為 1968 年**，之後修訂），提出**三模式**。
- Weil（1996），提出八模式。
- 考試以 Rothman 三模式為主。

## 五、Rothman 三模式

| 項目 | 社區發展 | 社會計畫 | 社會行動 |
|---|---|---|---|
| 假設 | 廣泛參與 | 專家能找出並解決問題 | 弱勢者的權益受到壓迫 |
| 目標 | 過程目標 | 任務目標 | 權力資源的再分配 |
| 策略技術 | 溝通與協商 | 事實發現與分析 | 衝突技術 |
| 媒介 | 社區團體 | 正式組織 | 弱勢團體與倡導者 |
| 工作者角色 | 使能者 | 專家 | 倡導者與行動者 |
| 案主角色 | 參與者 | 消費者 | 弱勢者 |
| 優點 | 凝聚社區，培養自主能力 | 效率高，問題解決有系統 | 能直接爭取權益 |
| 缺點 | 過程慢，難以處理複雜問題 | 居民參與少 | 容易引發衝突 |

- 社會行動不等於社會運動。
- 口訣（本片自編）：**發展用參與、計畫靠專家、行動爭權益**。

## 六、模式的選擇與轉換

- 同質性高、居民有共識 → 社區發展。
- 問題複雜、需要專業分析 → 社會計畫。
- 強勢壓迫、權益受損 → 社會行動。
- 常見轉換：行動 → 計畫（爭取權益後，需要規劃資源）；發展 → 行動（凝聚後，發現需要改變制度）。

## 國考重點

- **112 年**：夥伴關係的敘述，何者錯誤？答 **C**，批判與挑戰當前健康政策執行，不是有利因素。
- **111 年**：賦權的敘述，答 **D**，政策改變只是可能的結果，不是主因。
- **111 年**：增能的做法，答 **B**，盤點在地資源、建立夥伴關係並扶植。
- **111 年**：社區發展的核心原則，答 **C**，「個人充權」不是核心原則；核心原則是參與、社區導向與社會正義。
