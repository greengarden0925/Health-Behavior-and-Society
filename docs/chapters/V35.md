# V35 PRECEDE-PROCEED 模式

## 學習目標

1. 說明 PRECEDE-PROCEED 模式的產生背景與全名。
2. 依序說出九階段，並分辨規劃（五階段）與執行評價（四階段）。
3. 區分素質（傾向）、使能、增強三類因素，並各舉例。
4. 區分過程評價、衝擊評價與成果評價。
5. 能用此模式規劃一個健康促進計畫。

## 一、產生背景與全名

- **PRECEDE**：Predisposing, Reinforcing, and Enabling Causes in Educational Diagnosis and Evaluation（教育診斷與評價中的傾向、增強與使能因素），由 Green 等人於 1980 年提出。
- **PROCEED**：Policy, Regulatory, and Organizational Constructs in Educational and Environmental Development（教育與環境發展中的政策、法規與組織因素），1991 年加入。
- 核心精神：把行為理論融入健康促進活動，**由結果倒推原因**，再以評價回頭檢核。

## 二、九個階段

| 類別 | 階段 | 內容 |
|---|---|---|
| **規劃（PRECEDE）** | 階段 1：社會評估 | 生活品質、社會福利、失業率等社會指標 |
| | 階段 2：流行病學評估 | 罹病率、死亡率、生育率 |
| | 階段 3：行為與環境評估 | 行為指標與環境指標 |
| | 階段 4：教育與組織評估 | 三因素：素質、使能、增強 |
| | 階段 5：行政與政策評估 | 政策、法規與組織資源 |
| **執行與評價（PROCEED）** | 階段 6：執行 | 依計畫推動方案 |
| | 階段 7：過程評價 | 執行的優缺點、資源運用與進度 |
| | 階段 8：衝擊評價 | 行為與環境的改變 |
| | 階段 9：成果評價 | 健康與生活品質的改變 |

- 講義強調兩點：目標群體的參與，以及環境因素的重要性。

## 三、規劃階段的重點

- **階段 1 與 2**：社會指標與流行病學指標。
- **階段 3**：
    - 行為指標：遵從性、因應、自我照顧、預防疾病行為、資源應用。
    - 環境指標：經濟負擔能力、生理、生物、社會環境，以及所提供的服務。
- **階段 4 的三因素**：

    | 因素 | 意思 | 例子 |
    |---|---|---|
    | **素質**（傾向） | 人口特徵、社會結構、健康信念（知識、態度、信念、價值、知覺、自信） | 對防跌的知識與信心 |
    | **使能** | 資源與技能、個人與社區資源的可近性 | 有防跌課程、交通方便 |
    | **增強** | 他人的回應，如家人、醫療人員、雇主的誘因或獎懲 | 家人鼓勵、醫師提醒 |
- 口訣（本講義自編）：**想不想（素質）、能不能（使能）、有沒有人挺（增強）**。

## 四、版本差異

- 講義的英文寫作 Educational & Ecological Diagnosis。
- 較新的八階段版本，把社會、流行病與行為環境合併，其餘為教育與生態、行政與政策、執行、過程、衝擊與成果評價。
- **考試以講義的九階段為準。**

## 五、執行與評價（PROCEED）

- **過程評價**：檢視標的的素質、增強與使能是否到位，找出優缺點。順序是由第六階段往回檢核到第一階段。
- **衝擊評價**：評估行為與環境的改變。
- **成果評價**：評估健康與生活品質，包含流行病學診斷評價與社會學診斷評價。

## 六、公共衛生應用

- Kim 等（2022, *Systematic Reviews*）：統合 26 篇研究（其中 11 篇進行統合分析）。以「知識」為指標的隨機對照試驗（7 篇）效果量為 3.64（95% CI 1.95–5.33）；準實驗研究（4 篇）為 1.68（95% CI 0.75–2.61）。異質性很高（I² 分別為 98% 與 95%）；校正出版偏誤後為 1.73。
- 注意：高異質性代表結果差異大，解讀時要謹慎。

## 七、示範：高齡者防跌（本講義整理，非官方內容）

- 依衛福部 2025 年 2 月的「防跌三步」：65 歲以上約六分之一曾經跌倒；意外死亡的原因中，跌倒排名第二。
- 三步：
    1. 營養與運動。
    2. 慢性病管理。
    3. 用藥安全與自我評估。
- 以 PRECEDE 進行規劃：
    - 階段 1：社會評估（獨居、交通）。
    - 階段 3：行為（規律運動）與環境（居家安全）。
    - 階段 4：素質（防跌知識與信念）、使能（防跌課程）、增強（家人鼓勵）。
- 以 PROCEED 進行評價：過程評價看參與率；衝擊評價看運動與居家環境的改變；成果評價看跌倒率與生活品質。

- **114 年**：最強調生活品質觀點的評估，答 **A**，社會評估。
- **114 年**：下列何者錯誤？（衝擊評價不是「計畫結束一段時間之後」的評價），答 **A**，依講義答案。
- **112 年**：職場健康促進的評價，答 **A**（題目細節以官方試卷為準）。
- 辨析：
    - 「生活品質」「目標群體認為重要」→ 社會評估（階段 1）。
    - 過程評價＝執行優缺點與資源運用；衝擊評價＝行為與環境改變；成果評價＝健康與生活品質。
    - 素質＝知識、態度、信念；使能＝資源與技能；增強＝他人回應（家人、醫療人員、雇主）。
