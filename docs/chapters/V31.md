# V31 社會學習理論與社會認知理論

## 學習目標

1. 區分社會學習理論（Social Learning Theory, SLT）與社會認知理論（Social Cognitive Theory, SCT）。
2. 說明 SCT 的六個核心概念。
3. 說明三元交互作用的三類因素與三個行為形成機制。
4. 說出自我效能的四種來源，並辨識不屬於來源的選項。

## 一、班杜拉（Bandura）兩個理論的關係

- 班杜拉先發展 SLT，後發展 SCT。
- SCT 是在 SLT 的基礎上，納入認知過程。

## 二、社會學習理論（SLT）

- 人類學習不只靠直接的強化或懲罰，主要透過**觀察與模仿**。
- 核心：觀察學習、模仿、強化與懲罰。
- 講義例子：幼兒園老師誇獎有禮貌的小朋友並給糖果，旁觀的小孩日後也會變得有禮貌。
- 性別角色也是透過社會環境學得。
- 講義 434 頁在 SLT 之下列出**效能預期**（Efficacy expectations）與**結果預期**（Outcome expectations）。

## 三、社會認知理論（SCT）的六個核心概念

1. **自我效能**（Self-efficacy）：相信自己能做到某件事。
2. **結果預期**（Outcome expectations）：相信行為會帶來什麼結果。
3. **觀察學習**（Observational learning）。
4. **行為能力**（Behavioral capability）：知道怎麼做，並有能力執行。
5. **三元交互作用**（Reciprocal determinism）。
6. **自我調節**（Self-regulation）。

## 四、三元交互作用

| 因素 | 內容 |
|---|---|
| 個人因素 | 知識、態度、價值觀、自我效能 |
| 環境因素 | 有影響力的角色模範、社會規範的支持、資源與設備的可用性 |
| 行為因素 | 現有或過去的行為型態 |

- 三者彼此相互影響，不是單向因果。講義三元交互作用圖為圖片頁，本講義依文字重述。

## 五、三個行為形成機制

- **替代過程**：透過觀察他人的行為與結果學習。
- **認知過程**：符號化、目的性與預見性。
- **自我調節過程**：自己設定目標、監控與獎勵自己。

## 六、SLT 與 SCT 比較

| 比較 | SLT | SCT |
|---|---|---|
| 重點 | 觀察模仿、強化與懲罰 | 行為、環境與認知的交互作用 |
| 自我效能 | 講義比較表寫「未明確提出」 | 核心構念 |
| 自我調節 | 較少強調 | 強調 |

- 注意：Bandura 於 1977 年發表自我效能的論文，SCT 之後才把自我效能當成核心構念。**考試依講義比較表作答**：看到「自我效能、三元交互作用」→ SCT；只談觀察模仿與強化懲罰 → SLT。

## 七、自我效能的四種來源（口訣：成、替、口、生）

| 來源 | 意思 | 例子 |
|---|---|---|
| **過去成功經驗**（成） | 過去做到過，就更相信自己做得到 | 之前戒菸成功過一次 |
| **替代性經驗**（替） | 看到和自己相似的人成功 | 看到同齡朋友完成減重計畫 |
| **口語說服**（口） | 他人的鼓勵與肯定 | 醫師說「你做得到」 |
| **生理及情緒狀態**（生） | 身體與情緒的感受會影響信心 | 緊張、疲累時信心較低 |

- **「教導更多相關知識」不屬於自我效能的來源。**

## 八、公共衛生應用

- Ibeneme 等（2024, *BMC Geriatrics*）：8 個隨機對照試驗、1,546 位 60–85 歲社區長者，以計步器為基礎的步行計畫。身體活動的標準化平均差為 0.44（95% CI 0.26–0.61）；收縮壓有改善，舒張壓不顯著。作者指出，以社會認知理論與自我效能理論為基礎的介入，與較好的身體活動成果有關。
- 證據限制：偏誤風險中等到高；結果不能直接歸因於 SCT 本身。
- 方案設計（本講義整理）：小目標、同儕示範、計步器的自我監測、改善步道環境。
