# V26 捷思法與認知偏誤

## 學習目標

1. 說明捷思法（heuristics）的定義，區分可得性、代表性、錨定與調整三種捷思。
2. 說明每種捷思如何造成認知偏誤。
3. 區分認知偏誤、物理（知覺）偏誤、樂觀偏誤、信念偏誤。
4. 說明樂觀偏誤與疫苗溝通的公共衛生應用。

## 一、捷思法

- 定義：依據有限知識或不完整資訊，在短時間內找到解決方案的技術；依賴經驗判斷的法則。
- 捷思法讓人快速判斷，但容易產生偏誤。

## 二、三種捷思

| 捷思 | 判斷方式 | 偏誤例子（講義） |
|---|---|---|
| **可得性** | 從記憶中立即找出可用的事例 | 熟悉的事情看起來重要，陌生的事情看起來不重要。講義引用《真確》（Factfulness）的調查：赤貧人口問題，近 12,000 人中只有 7% 答對。 |
| **代表性** | 依與母體特徵的相似程度判斷 | 前車開得慢，就認定「一定是馬路三寶」，屬於刻板印象。 |
| **錨定與調整** | 先有直覺的起點，再往上或往下調整，但調整往往不足 | 澎湖島嶼數題，提示數字為 20，答案卻落在 20 附近；講義答案為 64 個島嶼。 |

- 赤貧問題的正確答案是「幾乎減半」。補充：Gapminder 的資料顯示，極端貧窮人口比例由 1997 年的 29.5% 降到 2017 年的 9.1%。調查答對率依樣本而異。
- 講義 395–396 頁為直覺與錯覺的圖片頁（如 Ebbinghaus 與 Müller-Lyer 錯覺），文字擷取不到，請對照講義原圖。

## 三、四種偏誤

| 偏誤 | 意思 | 例子 |
|---|---|---|
| **認知偏誤** | 用主觀解釋客觀事件 | 對統計數據的錯誤理解 |
| **物理（知覺）偏誤** | 感官知覺造成的錯誤判斷（講義英文 Perceptual Bias） | 視覺錯覺 |
| **樂觀偏誤** | 「最衰的不是我」，低估自己遇到風險的機率 | 有高血壓卻認為自己不會得慢性病 |
| **信念偏誤** | 既有信念影響對事實的判斷 | 堅信某做法有效，忽略反證 |

- 樂觀偏誤補充：Weinstein（1980）發現，學生認為自己離婚、酗酒的風險低於同學。
- 樂觀偏誤的影響：可能減少預防行為與戒菸意圖。但在不可逆的情境中，它也可能讓人維持動機。

## 四、公共衛生應用

- 風險溝通不只講平均風險，要讓對象看見與自己有關的風險。
- 疫苗溝通要先了解對象原本的信念，再設計訊息。Vandeberg 等（2022, *Frontiers in Psychology*）的研究未發現疫苗敘事會引發可得性捷思，原本的疫苗猶豫影響較大。

## 國考重點

- **112 年**：受害者責備的敘述，何者錯誤？答 **B**（僅著重個人層次因素）。
- **112 年**（已用考選部官方題庫核對，原教案記為 111 年有誤）：卡車司機有高血壓與高血脂，卻認為自己不太可能得慢性病，屬於哪一種偏誤？答 **C**，樂觀偏誤。
- 名詞辨析：「物理偏誤」在講義中對應英文 Perceptual Bias，較貼切的中文是知覺偏誤。
