# V06 慢性病調適與動機式晤談

## 學習目標

1. 說出 Shontz 慢性病反應的四階段，並知道英文教科書常見的三階段版本。
2. 說出 Moos 危機理論的三組因素與因應歷程三要件。
3. 說明動機式晤談（Motivational Interviewing, MI）的定義、起源、原則與 OARS 技術。
4. 知道 MI 在公共衛生的證據與限制。

## 一、Shontz 慢性病反應階段
講義版四階段：**驚嚇（shock）→ 面對（encounter）→ 退縮（retreat）→ 調適（adjustment）**。重點在情緒與行為因應。

- 英文教科書常列三階段：shock、encounter、retreat（退縮後逐漸接受）。
- 考試時先確認題目用的是哪一個版本。

## 二、Moos 危機理論

- 三組因素：**背景與個人因素**、**疾病相關因素**、**生理及社會環境因素**。
- 因應歷程三要件：**認知評估**（第一步）、**因應任務**（講義寫「調適決策」，分兩大部分）、**因應技巧**。
- 預想未來事件、規劃情境，是有用的因應技巧。

## 三、動機式晤談（MI）

- **定義**：以案主為中心、又帶有方向性的合作式對話，目的是引發改變的動機。
- **起源**：Miller 1983 年提出，最早用於酒癮與物質濫用；1991 年與 Rollnick 進一步發展。
- **核心概念**：矛盾心理（ambivalence），即一個人同時想改變、又不想改變。
- **講義四原則**（早期框架）：表達同理心、創造不一致、與抗拒纏鬥、支持自我效能。
- **OARS 技術**：開放式問句（Open questions）、肯定（Affirmations）、反映式傾聽（Reflections）、摘要（Summaries）。
- **2013 年第 3 版的新架構**：精神（合作、接納、關懷、引發）與四歷程（建立關係、聚焦、引發、計畫）。中文譯名各書不同。

## 四、公共衛生應用

- Davies et al.（BMJ, 2026）：疫苗接種促進介入的成分網絡統合分析，納入 237 項研究、4,361,717 位參與者。成人「動機式晤談」成分的勝算比為 1.79（95% CrI 1.21–2.64）。這是**成分分析**，不代表單獨使用 MI 就有此效果。
- 台灣：戒菸服務補助計畫的項目為衛教、給藥、追蹤；戒菸專線 0800-636363。目前查到的公開文件未明訂使用 MI。

## 國考練習
**1.（111 年）** 下列何者不是動機式晤談的假設？
**解答：A**。MI 的假設是能強化內在動機；「無法增加內在動機」是錯誤敘述。

**2.（109 年，臨床心理師考題）** 關於 Moos 危機因應歷程的敘述，何者錯誤？
**解答：D**。「否認或最小化對病人無助益」屬於錯誤敘述。
