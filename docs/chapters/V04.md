# V04 人格、正向心理學與復原力

## 學習目標

1. 說出 A 型、B 型、C 型人格的特徵，以及 A 型與心血管疾病的關係。
2. 說明 Seligman 正向心理學三大支柱與「習得樂觀」。
3. 說明心理強韌（復原力）的意涵，並判斷相關考題的對錯。
4. 舉出人格與正向心理在公共衛生上的應用。

## 一、人格類型

| 類型 | 特徵 |
|---|---|
| A 型 | 表現欲與競爭心強、急躁沒耐心、對時間有緊迫感 |
| B 型 | 缺乏時間緊迫感與競爭意識、享受生活、性情溫和 |
| C 型 | 認真、一絲不苟、壓抑情感、顧慮別人、不擅長競爭 |

- **A 型**：Friedman 於 1959 年提出，認為心血管疾病與性格、行為有關。
- 後來研究發現，A 型中與心臟病關係最明確的是**敵意與憤怒**。Chida & Steptoe（2009）統合分析：憤怒與敵意使冠心病事件風險比為 1.19；已有冠心病者風險比為 1.24。
- **C 型**：講義寫 Temoshok（1992）提出；C 代表 Cancer（講義指在 150 位惡性腫瘤患者中，有四分之三屬於 C 型）。這是描述性觀察；後續研究沒有找到穩定的證據，證明人格特質會導致癌症。**考試要記特徵與命名由來，不要當成因果結論。**

## 二、正向心理學（Seligman）

三大支柱：

1. **正向情緒**：幸福不是完全沒有負面情緒，只要正面情緒多於負面，就是美滿的狀態。
2. **正向特質**：六大類，分別是智慧與知識、勇氣、人道與愛、正義、修養、心靈的超越。講義強調**習得樂觀**，樂觀是可以透過學習培養的。
3. **正向組織**：容易引發個人正向情緒的環境，例如家庭關係、人際互動、團隊合作。

## 三、心理強韌（復原力，resilience）

- 定義：正確識別情緒與情境、調節生理心理狀態、做出合適外在行為的能力。
- 復原力強的人，恢復得比較快，也比較不會把中性事件誤判成負面事件。
- 復原力**不是固定的天賦**，會由個人、家庭、社會中的保護因子與危險因子交織而成，並因情境與問題不同而有差異。

## 四、公共衛生應用

- **樂觀與心血管健康**：Rozanski et al.（2019）統合分析，15 項研究、229,391 人、平均追蹤 13.8 年；樂觀者心血管事件風險比 0.65，全因死亡風險比 0.86。這是觀察性研究，不能直接證明樂觀造成長壽。
- **台灣政策**：
    - 教育部健康促進學校計畫，納入正向心理健康促進議題。
    - 全民心理健康韌性計畫（2025–2030），預計六年投入 56.3 億元，六大策略的第一項是全方位心理健康促進。

## 國考練習

**1.（112 年）** 下列關於復原力的敘述，何者錯誤？
（選項請見官方試題）**解答：B**。說復原力無法透過認知教育訓練或環境改變來強化，是錯的。

**2.（111 年）** 下列何者不屬於 Seligman 正向心理學的研究議題？
（選項請見官方試題）**解答：B**。引發憂鬱症的影響因子屬於致病因子，正向心理學研究的是正向功能。

**3.（111 年）** 健康促進學校的正向心理健康促進，下列何者錯誤？
（選項請見官方試題）**解答：C**。錯誤者是「整合心理疾患的一、二、三段預防」；正向心理健康強調幸福感與支持性環境。

**4.（111 年）** 下列關於復原力的敘述，何者錯誤？
（選項請見官方試題）**解答：A**。復原力具有情境與內容的特異性，不是不具特異性。
