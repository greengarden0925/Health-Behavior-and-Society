# V36 衛生教育計畫：原則與六步驟

## 學習目標

1. 說出五項衛生教育原則（準備、類化、自動、興趣、個別適應），並舉例。
2. 依序說出衛生教育計畫六步驟，並說明每步驟的工作內容。
3. 說明需要評估時，要同時考量需求（demand）與需要（need），並考量重要性、可行性、合意性。
4. 區分目標（goal）與子目標（objective）。
5. 說出評價的四項原則。

## 一、五項衛生教育原則

| 原則 | 意思 | 例子（戒檳榔衛教，本片整理） |
|---|---|---|
| **準備** | 教學前雙方都要準備，並引起動機 | 先說明檳榔與口腔癌的關聯，引起學習動機 |
| **類化**（統覺） | 用舊經驗解釋新事物，由已知到未知 | 從大家熟悉的香菸危害，類推到檳榔的危害 |
| **自動** | 佈置物理與心理環境，讓學習者主動參與 | 設計互動問答與討論 |
| **興趣** | 教材與方法要有變化 | 影片、故事、遊戲交替使用 |
| **個別適應** | 依學習者差異彈性分組，因材施教 | 依吸檳榔的頻率與意願分組 |

- 本片自編口訣：**準、類、動、趣、適**。

## 二、衛生教育計畫六步驟

1. **策動**（initiation）：瞭解服務對象的問題，並讓他們明瞭問題。
2. **需要評估**（need assessment）：同時考量需求（demand）與需要（need），並考慮重要性、可行性與合意性。
3. **目標設定**（goal setting）：分為目標與子目標。
4. **研擬計畫**（program planning）。
5. **執行**（implementation）。
6. **評價**（evaluation）：評價結果用來修訂計畫，形成循環。

## 三、需要評估的重點

- **需要（need）**：專家判斷的應有狀態與實際狀態的差距。
- **需求（demand）**：民眾自己感受到並願意採取行動的部分。
- 需要評估的方法常用問卷調查、第一手資料蒐集與焦點團體（本片整理）。
- 考量三項：
    - **重要性**：問題的嚴重程度與影響範圍。
    - **可行性**：人力、資源與時間是否足夠。
    - **合意性**：服務對象與社區是否接受。

## 四、目標與子目標

| | 目標（goal） | 子目標（objective） |
|---|---|---|
| 性質 | 廣泛、整體，指出方向與預期成果 | 特定、分段，是行為目標 |
| 作用 | 說明計畫要達到的總方向 | 是需要評估與計畫介入之間的橋樑 |

## 五、計畫書與執行的內容

- **計畫書內容**：前言、目的與宗旨、資源與限制、目標、方法與活動、執行方式、評價方式。
- **執行內容**：活動順序、訓練課程、工作人員訓練、報告、工作進度表。

## 六、評價的四項原則

1. 清楚陳述重點與總目標。
2. 記錄資料與成果要妥善保存。
3. 評價的方法與工具要高信度、高效度、客觀。
4. 評價結果要用來修訂計畫。

## 七、與 PRECEDE-PROCEED 的對照（本片整理）

- 策動＋需要評估 ≈ PRECEDE 階段 1–3。
- 目標設定＋研擬計畫 ≈ 階段 4–5。
- 執行 ≈ 階段 6。
- 評價 ≈ 階段 7–9。

## 八、公共衛生應用

- 衛福部「115 年度衛生教育主軸宣導計畫」（2025 年 12 月公布）的青少年檳榔健康危害防制，需要評估的依據包括：
    - 口腔癌每年新發病例超過 8 千人，每年死亡約 3 千人，癌症排名第 6。
    - 青少年中約 2.8% 曾經嚼食檳榔；逾三成在 11 歲以前有嘗試經驗；朋友與家人是主要來源，約 75%。
    - 逾四成民眾不清楚檳榔子本身會致癌。
- 預期績效：認知率達 65%；前後測 80 分以上者超過八成。
- 策略：校園與社區多元宣導、建立拒檳支持環境。
- 評價：定期以民意調查評估認知度與滿意度。

## 國考重點

- **112 年**：失智症問卷調查屬於哪一項？答 **D**，需求評估。
- 步驟順序：策動 → 需要評估 → 目標設定 → 研擬計畫 → 執行 → 評價。
- 「蒐集第一手資料、問卷調查了解認知」→ 需要評估階段。
- 目標是整體方向；子目標是行為目標。
- 評價工具須高信度、高效度、客觀；評價結果要用於修訂計畫。
- 講義本單元只收錄一題相關的歷屆考題；其餘練習皆為自編，不收錄。
