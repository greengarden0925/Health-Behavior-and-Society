# V24 行為理論（二）：健康信念模式與 Pender 健康促進模式

## 學習目標

1. 說明健康信念模式（HBM）的起源、三層面與六要素。
2. 背誦口訣「罹、嚴、利、礙、行、效」，並能用於考題判斷。
3. 以體重控制與校園毒品防制為例，練習申論題的作答方式。
4. 說明 Pender 健康促進模式的三大部分。
5. 說明 HBM 在疫苗與乳癌篩檢的應用。

## 一、健康信念模式（HBM）

- 1950 年代，Rosenstock 提出。源於美國公共衛生服務單位（USPHS）的社會心理學研究，目的是解釋為何一般人不願意參與疾病預防或早期發現計畫。
- 1970 年代，Kirscht（講義作「柯特 Kircht」）用於疾病症狀的反應；Becker 用於遵從醫囑。
- 1988 年，Rosenstock、Strecher、Becker 等把**自我效能**列為獨立構念，缺乏自我效能視同一種障礙。

## 二、三層面與六要素

| 層面 | 要素 | 意義 |
|---|---|---|
| 個人認知 | **罹患性**（Susceptibility） | 認為自己會不會得病 |
| | **嚴重性**（Severity） | 認為疾病後果有多嚴重；罹患性＋嚴重性＝自覺疾病威脅性 |
| 採取行動可能性 | **利益性**（Benefit） | 相信採取行動會有好處 |
| | **障礙性**（Barrier） | 認為行動會有困難或代價 |
| | **自我效能**（Self-efficacy） | 相信自己做得到 |
| 修飾因素 | **行動線索**（Cues to action） | 外在（大眾媒體、教育、親友勸告）或內在（身體症狀） |

- 修飾因素還包括人口變項、社會心理變項、結構變項（如知識、罹病經驗）。
- 口訣：**罹、嚴、利、礙、行、效**（行＝行動線索，效＝自我效能）。

## 三、申論示範

- **範例一**：體重控制預防糖尿病。逐項說明罹患性、嚴重性、利益性、障礙性、行動線索與自我效能，各給一句具體說明。
- **範例二**：校園毒品防制。依六要素設計措施，並寫出每項措施的目的。
- 作答原則：先寫該要素的定義，再寫本題情境，最後寫措施與目的。

## 四、Pender 健康促進模式

- 1982 年首見於 *Health Promotion in Nursing Practice*；1996 年修訂，新增行動相關感受、行動計畫承諾與立即面對的需求與喜好。
- 三大部分：
    1. **個人特質及經驗**：先前相關行為、個人生理、心理與社會文化因素。
    2. **行為特異性認知與情感**：利益、障礙、自覺自我效能、行動相關感受、人際影響、情境影響。
    3. **行為結果**：行動計畫承諾、立即面對的需求與喜好，最終導向健康促進行為，目的是建立正向健康生活型態。
- 理論基礎包括社會認知理論與期望價值理論。

## 五、公共衛生應用

- Limbu 與 Gautam（2023, *Vaccines*）系統性回顧 109 項 COVID-19 疫苗研究：在有檢驗的研究中，利益性約 90.6% 達顯著，障礙性約 85.2%，行動線索約 84.6%，自我效能約 77.8%，罹患性約 63.2%，嚴重性約 56.6%。
- Hsieh 等（2021, *Journal of Cancer Education*）：臺灣南部五家機構、621 位 45–69 歲女性。納入 HBM 構念後，知識的直接效果不顯著，障礙與行動線索是關鍵。
- 臺灣政策：國民健康署的乳房 X 光攝影篩檢，2025 年起擴大為 40–74 歲女性每兩年一次免費（原為 45–69 歲，及 40–44 歲有家族史者）。使用前請至官網確認現行規定。
- 應用方向（本講義整理）：
    - 罹患性低 → 用本地數據與個案說明。
    - 嚴重性低 → 說明後果。
    - 利益性低 → 強調好處。
    - 障礙性高 → 降低時間、費用與取得困難。
    - 缺行動線索 → 通知與提醒。
    - 自我效能低 → 技能練習與角色扮演。

## 國考重點

- 乳癌篩檢的「可能性」：自覺罹患性（112 年，答 C）。
- 懷疑疫苗效果：自覺利益（111 年，答 C）。
- 不屬期望價值理論的是社會學習理論（114 年，答 D）。
- HBM 的六要素要能逐一對應情境，申論題常以此作答。
