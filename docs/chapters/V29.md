# V29 行為主義學習理論：嘗試錯誤、古典制約、操作制約

## 學習目標

1. 說明桑代克的嘗試錯誤學習與學習三律。
2. 區分古典制約與操作制約，並說出古典制約的五個現象。
3. 用正增強、負增強、正懲罰、負懲罰四象限分類實例，並分辨增強與懲罰。
4. 說明制約原理在衛生教育的應用。

## 一、桑代克與嘗試錯誤

- 桑代克（Thorndike）的貓迷籠實驗：貓偶然碰到門把，開門取得食物；之後紊亂動作逐漸減少。
- **學習三律**：
    - **效果律**：滿足的後果使聯結增強。
    - **練習律**：練習次數增加，聯結增強。
    - **準備律**：身心的準備狀態影響學習。
- 後期修正：「滿意與不滿意」改為「增強與懲罰」；效果律不再主張懲罰會削弱聯結；練習要有獎勵才有效。

## 二、行為學習理論（S-R 理論）

- 以刺激與反應的連結解釋學習。
- 重視環境與外在控制，強調可觀察的行為改變。
- 主張增強與懲罰兼施。

## 三、古典制約（Pavlov）

- 中性刺激（CS）多次與非制約刺激（UCS）配對後，中性刺激單獨出現，也能引發類似的反應，稱為**制約反應（CR）**。
- 刺激替代：中性刺激取代了原本的非制約刺激。

**五個現象**：

| 現象 | 意思 |
|---|---|
| 消弱（Extinction） | 制約刺激單獨出現多次，制約反應逐漸消失 |
| 自發恢復（Spontaneous Recovery） | 消弱後，過一段時間制約反應又出現 |
| 類化（Generalization） | 相似的刺激也引發同樣反應 |
| 辨別（Discrimination） | 能分辨出制約刺激與相似刺激的差異 |
| 高次制約（Higher-order Conditioning） | 已形成的制約刺激，可再與新的中性刺激配對 |

- 講義的「玉米濃湯」例子：玉米濃湯（強化物）→ 努力讀書；考試類似有湯喝（類化）；背單字沒有湯（辨別）；媽媽不煮後又想喝（消弱與自發恢復）；點數卡可以換湯（二級制約與二級強化）。
- 注意：這個例子的「考九十分→有湯喝」，行為之後有獎勵，本質屬於操作制約。類化、辨別、消弱、自發恢復與高次制約在兩種制約中都可能出現。

## 四、操作制約（Skinner）

- 自發的反應之後給予增強刺激，使該反應更容易再發生。
- Skinner 箱（講義稱工具制約）：老鼠壓桿得到食物，關鍵在於增強作用的安排。

**四象限**：

| | 給予刺激 | 拿掉刺激 |
|---|---|---|
| 想要的刺激 | **正增強**：行為增加 | **負懲罰**（第 II 型）：行為減少 |
| 不想要的刺激 | **正懲罰**（第 I 型）：行為減少 | **負增強**：行為增加 |

- 口訣：正負看「給或拿」；增強或懲罰看「行為變多或變少」。
- 負增強與懲罰的區別：負增強是拿掉不想要的東西，使行為增加；懲罰是給予不想要的東西或拿掉想要的東西，使行為減少。

## 五、古典與操作的對照

| | 古典制約 | 操作制約 |
|---|---|---|
| 聯結 | 刺激與刺激（S-S） | 行為與後果 |
| 反應 | 被動、非自主 | 主動、自發 |
| 例子 | 化療病人看到醫院就緊張 | 護理人員整理病房被表揚，之後更常整理 |

## 六、衛生教育的應用

- **後果即時**：行為發生後，獎勵或回饋要盡快給予。
- **多增強、少懲罰**：懲罰容易引起反感與逃避。
- **增強時制**：
    - 固定時距（如月薪）。
    - 固定比率（如按件計酬）：增強一旦消失，行為消退較快。
    - 不固定比率與不固定時距：行為最持久，如賭博容易上癮。
- 懲罰不等於羞辱。
- **消弱突然爆發**：突然停止增強，行為可能會爆發式增加，應逐步撤除。
- **反制約**：以新的、相容的反應取代舊的反應。例如戒菸時，以放鬆、運動或戒菸貼片作為替代行為。經典例子是 Mary Cover Jones 的兔子實驗，讓孩子在吃喜歡的食物時，逐步接近兔子。

## 七、公共衛生應用

- Notley 等（2025, *Cochrane Database*）：48 項隨機對照試驗，戒菸誘因（長期至少 6 個月）的戒菸相對危險度為 1.52（95% CI 1.33–1.74）；孕婦族群為 2.13。誘因金額高低差異不明顯。
- 菸稅與無菸環境：每包 20 元菸捐自 2009 年起未調整。菸害防制法規定衛福部與財政部每兩年檢討。

## 國考重點

- **112 年**：提高菸稅、設置無菸場所，屬於哪一種原理？答 **A**，處罰原理。
- **108 年**：操作制約強調行為習得是因為行為所帶來的後果，答 **A**。
- 辨析：增強（行為增加，含正、負）與懲罰（行為減少，含正、負）。
- 時制：不固定比率與不固定時距最持久。
