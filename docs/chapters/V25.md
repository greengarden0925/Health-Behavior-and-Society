# V25 行為理論（三）：COM-B 與行為改變輪

## 學習目標

1. 說明 COM-B 三要素（能力、機會、動機）及其細項。
2. 說明行為改變輪（Behaviour Change Wheel, BCW）的三層結構。
3. 列出九種介入功能與定義，並能把介入功能對應到缺口。
4. 以「鼓勵員工走樓梯」示範 COM-B 診斷與介入設計。
5. 說明 COM-B 與 BCW 在公共衛生的應用。

## 一、COM-B 模式

- **C（Capability，能力）**：生理與心理層面，包括技術、知識與心理素質。
- **O（Opportunity，機會）**：物理環境與社會環境。
- **M（Motivation，動機）**：包括目標設定、習慣性、情感反應與分析性決策。
- 核心觀點：只有當人有**能力**與**機會**實行某行為，並有**動機**去實踐，行為才會發生。
- 能力與機會的作用是調節動機與行為之間的關係，動機要在能力和機會的通道都打開時，才會轉化為行為。
- 行為本身也會回過頭影響能力、機會與動機。

## 二、行為改變輪（BCW）

- **最內層**：COM-B 三要素。
- **中層**：九種介入功能（intervention functions）。
- **最外層**：七種政策類別（policy categories）。

## 三、九種介入功能

| 介入功能 | 定義 |
|---|---|
| 教育（Education） | 增加知識或理解 |
| 說服（Persuasion） | 用溝通引發正向或負向感受，促使行動 |
| 誘因（Incentivisation） | 創造獲得獎勵的預期 |
| 強制（Coercion） | 創造受罰或付出代價的預期 |
| 訓練（Training） | 傳授技能 |
| 限制（Restriction） | 用規則減少從事目標行為的機會 |
| 環境重構（Environmental restructuring） | 改變物理或社會情境 |
| 示範（Modelling） | 提供可模仿的榜樣 |
| 賦能（Enablement） | 增加資源、減少障礙，提升能力或機會 |

## 四、七種政策類別
溝通與行銷、指引、財政、規範、立法、環境與社會規劃、服務提供。

## 五、範例：鼓勵員工走樓梯

| 缺口 | 介入功能 | 做法 |
|---|---|---|
| 能力 | 教育 | 健康教育，讓員工知道走樓梯的好處 |
| 機會 | 環境重構 | 在電梯旁放醒目標誌，引導走樓梯 |
| 動機 | 說服、誘因 | 標語宣導、挑戰賽、獎勵 |

## 六、公共衛生應用

- Mersha 等（2023, *BMC Public Health*）：以 BCW 與修正德爾菲法，邀請 17 位專家經兩輪討論，找出 13 項改善戒菸藥物遵從性的策略，並將障礙對應到 COM-B。
- 菸害防制：立法與規章、限制取得與使用菸品的機會，屬於減少機會的做法；警示圖文屬於說服；戒菸服務屬於賦能（本講義整理）。
- 臺灣菸害防制法 2023 年 3 月 22 日施行的修正，包括全面禁止電子煙、加熱菸須經健康風險評估、吸菸年齡提高到 20 歲、警示圖文占 50%。

## 七、BCW 設計步驟（本講義整理）

1. 界定目標行為。
2. 用 COM-B 診斷缺能力、機會或動機。
3. 選擇介入功能。
4. 選擇政策類別。
5. 評價成效。

## 國考重點

- 113 年：COM-B 的敘述，何者錯誤？答 **B**。錯誤敘述是「能力與機會可直接影響行為」；正確說法是能力與機會調節動機與行為的關係。
- 口訣（本講義整理）：**不會做補能力、沒條件改機會、不想做提動機**。
- 記住 COM-B 的 C 與 O 是「做得到」，M 是「想去做」。
