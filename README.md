# 健康社會行為學講義

公共衛生師國考「健康社會行為學」複習講義（V00–V40，共 41 章），章末附歷屆國考題（110–115 年，240 題，考選部公告答案）。

- 內容：`docs/chapters/Vxx.md`，每章一個檔
- 站台：Zensical（相容 MkDocs Material 設定），推送到 `main` 後由 GitHub Actions 自動發布
- 維護方式：見 [`docs/maintenance.md`](docs/maintenance.md)

## 本機預覽

```bash
pip install -r requirements.txt
zensical serve
```

## 注意

講義依影片教案整理；國考題與答案來源為考選部公告，正式作答請以考選部官方試卷為準。
